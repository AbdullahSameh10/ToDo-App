# 📝 ToDo App

A modern and interactive ToDo application built using **HTML**, **CSS**, and **JavaScript**.  
This project helps users organize their daily tasks with a clean UI, smooth interactions, and useful productivity features.

---

## ✨ Features

### 📌 Task Management
- ➕ Add new tasks easily
- ✏️ Edit existing tasks
- ✅ Mark tasks as completed
- ❌ Delete tasks

---

### 🎨 Modern User Interface
- 🌙 Dark / Light theme support
- 📱 Fully responsive design
- ✨ Smooth and clean user experience
- 🌐 Full Arabic language support
- ✔ Hide completed tasks

---

### 🔔 Custom Popup System
This project includes a fully customized popup window system instead of using the browser's default dialogs.

#### Features:
- 🛠️ Custom edit popup window
- ⚠️ Custom delete confirmation popup
- 🎯 Better user experience and modern design

---

### 🍞 Toast Notification System
Beautiful toast notifications appear after actions to improve user feedback.

#### Examples:
- ✅ Task added successfully
- ✏️ Task edited successfully
- ❌ Task deleted successfully

---

### 💾 Local Storage Support
Tasks are automatically saved in the browser using **Local Storage**.

This means:
- 🔄 Tasks remain saved after refreshing the page
- 💻 No database required
- ⚡ Fast and lightweight

---

### 🖱️ Drag & Drop Sorting
Users can reorder tasks بسهولة using drag-and-drop functionality.

#### Benefits:
- 📂 Better task organization
- ⚡ Interactive experience
- 🎯 Easy prioritization

---
